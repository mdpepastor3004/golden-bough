왜 만들었나

"인터넷이 존재하는 한 이론상 꺼지지 않는 엔진"이 가능할까?

LLM 시대에 데이터는 매일 폭증한다. 게시글·논문·코드·이미지·대화·로그. 인간이 멈추지 않는 한, AI가 멈추지 않는 한 데이터는 고갈되지 않고 증가한다. 그 데이터를 연료로 삼는 닫힌 루프가 있다면 — 문명이 데이터를 생산하는 한 도는 엔진.

GoldenBough는 그 루프의 작동 프로토타입이다. 흡입 → 선별 → 변환 → 방출 → 재점화 5단계를 거치며, 방출된 결과가 다시 다른 사람/AI의 연료가 되어 돌아온다.

5개 모듈

📥

1. 흡입 (Ingest)

RSS 6 + API 3 + 정적크롤러 3 + Playwright을 병렬로 흡입. JSON Lines로 날짜별 파티션 저장. feedparser/requests 의존성만.

🔍

2. 선별 (Filter)

중복 제거(id+hash) → 노이즈 차단 → 0~100 가치 스코어링(소스가중치·길이·키워드·도메인) → 카테고리 클러스터링.

🔄

3. 변환 (Transform)

TextRank 추출 요약(numpy PageRank) + 키워드 TF + 인사이트 카드 생성. 선택적 LLM 임팩트 강화(OpenAI/Anthropic/Google).

📤

4. 방출 (Emit)

HTML 대시보드 + Markdown 뉴스레터 + JSON API. 환경변수만 주면 텔레그램/디스코드 자동 발송까지.

🔥

5. 재점화 (Feedback)

반응 추적(view/like/share/click) → 가중치 동적 재계산 → 다음 ingest 설정 자동 갱신. 폐루프 완성.

빠른 시작 (5분)

1. 클론 & 설치

git clone https://github.com/yourname/golden-bough.git cd golden-bough pip install -r requirements.txt

2. 환경변수 (선택)

export GOLDEN_BOUGH_ROOT=$(pwd) # 선택 — LLM 임팩트 강화 export OPENAI_API_KEY=sk-... # 선택 — 텔레그램 발송 export TELEGRAM_BOT_TOKEN=... export TELEGRAM_CHAT_ID=...

3. 1회 풀사이클

bash deploy/golden_bough.sh once

4. 산출물 확인

ls data/output/ # → dashboard_2026-08-24.html # → newsletter_2026-08-24.md # → api_2026-08-24.json

5. 30분마다 자동실행

bash deploy/golden_bough.sh install-cron

수익화 루프

방출 → 사용자 반응 → 재점화 → 더 가치있는 데이터 → 더 나은 산출물 → 더 많은 유입 → 반복. 선순환.

맞춤형 분석

설계 원칙

  • 무거운 의존성 0 — numpy + requests + feedparser + httpx. PyTorch/Transformers 없이 동작.
  • 단일 명령으로 5단계 실행 — bash deploy/golden_bough.sh once 한 줄.
  • 환경변수 fallback — API 키 없으면 룰 기반 모드, 있어도 graceful.
  • 날짜 파티션 — raw/curated/knowledge/output 모두 YYYY-MM-DD/ 분리.
  • JSON Lines — grep/jq 한 줄로 어디서든 디버깅.
  • 동적 가중치 — 매 사이클 끝에 ingest 설정이 자동 갱신.
